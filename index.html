O que é um seletor CSS?

Um seletor CSS é uma expressão que define quais elementos HTML serão estilizados por uma regra CSS.

            
                p {
                color: blue;
                }

Aqui:
p = seletor. Ele seleciona todas as tags do HTML

Tipos de seletores CSS

Seletor Universal

O seletor universal é representado pelo asterisco (*) e seleciona todos os elementos do documento.

            
                * {
                margin: 0;
                }

Seletor de Tipo (ou elemento)

O seletor de tipo seleciona elementos com base no nome da tag HTML. 

            
                p {
                color: red;
                }

Aqui: Aplica em todos os h1 do HTML

Seletor de Classe

Seleciona elementos com uma classe específica. 

            
                .destaque {
                background-color: yellow;
                }

Utiliza um "." antes do nome no css para identificar.

Seletor de ID

Seleciona um elemento com ID específico (único). 

            
                #menu {
                background-color: gray;
                }

Utiliza um "#" antes do nome no css para identificar.
Deve ser único na página.
